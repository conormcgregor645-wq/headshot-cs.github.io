# TASHER: VIP-меню и рейтинг на табло CS2

## VIP-меню

Команда в игре: `!vip` (или `css_vip`). В меню **только бонусы**, которые можно включать и выключать: деньги,
регенерация, вампиризм — одним списком, у каждого `ВКЛ` / `ВЫКЛ`. Снаряжение статуса (здоровье, броня, набор сапёра,
гранаты, шприц, Zeus) выдаётся автоматически и в меню не показывается. Админ-меню `!vip_admin` — в том же стиле.

| Кнопка | Действие |
| --- | --- |
| `W` / `S` | Выбор пункта |
| `E` | Включить/выключить или выбрать пункт |
| `R` или `Tab` | Закрыть меню |

- Пока меню открыто, игрок стоит на месте (и в начале нового раунда тоже); после закрытия движение возвращается.
- Меню открывается только живому игроку — мёртвому приходит сообщение в чат. Настройки действуют со следующего возрождения.
- Через 30 секунд без нажатий меню закрывается само.
- Панель отправляется игроку каждый тик: иначе её перебивают подсказки игры и она мигает.
- Две колонки не используются: панель узкая, и строки с длинными названиями переносились.

### Почему не полная копия меню закупки

Меню закупки рисует сам клиент игры (Panorama). Серверный плагин может показать только текстовую HTML-панель в центре
экрана — поэтому вкладки и карточки, без мыши и картинок оружия.

## Очки рейтинга в CS2

- В **клановом теге (Tab)** теперь только название статуса `VIP`, `PREMIUM`, `KING` и т.п., без чисел рейтинга.
- В `tasher_player.pts` сайт передаёт **очки текущего месяца**, которые совпадают с месячной таблицей лидеров сайта.
- В плагине TASHER Style предусмотрена **отдельная** запись `CompetitiveRanking` / `CompetitiveRankType=11` (тип Premier) вместо приписывания чисел в `Clan`.

### Ограничение безопасности Valve

CounterStrikeSharp предупреждает, что изменение некоторых полей матчмейкингового ранга может привести к бану **Game Server Login Tokens (GSLT)**. Защитная настройка `FollowCS2ServerGuidelines` блокирует такие операции.

Поэтому в конфигурации **по умолчанию**:

```json
"PremierScoreboardEnabled": false
```

Плагин *не отключает* `FollowCS2ServerGuidelines`. Даже если пользователь включит `PremierScoreboardEnabled`, при активной защите модуль не станет изменять поля Premier и запишет предупреждение. Это не обещание работающего значка Premier на стандартном Public-сервере: видимость штатного поля также зависит от режима игры и версии клиента CS2. Не рекомендуется снимать защиту CounterStrikeSharp ради косметического отображения рейтинга без осознанного принятия риска владельцем сервера.

Очки рейтинга доступны без этого риска через `!rank` и на сайте TASHER.

Источники: [CounterStrikeSharp — Core Configuration](https://docs.cssharp.dev/docs/reference/core-configuration.html), [CCSPlayerController CompetitiveRanking](https://docs.cssharp.dev/api/CounterStrikeSharp.API.Core.CCSPlayerController.html).

## Публикация

1. Слить одобренный PR в `main` после проверок GitHub Actions (Node и сборки C#).
2. Дождаться новых архивов [VIPCore](https://github.com/conormcgregor645-wq/headshot-cs.github.io/releases/tag/vipcore-tasher) и [TASHER Style](https://github.com/conormcgregor645-wq/headshot-cs.github.io/releases/tag/tasherstyle).
3. На VPS выполнить `tasher-update` (обновит код сайта); отдельно в согласованное время запустить `bash /opt/tasher/server/deploy/vip-setup.sh` (остановит/перезапустит CS2).
4. Проверить `!vip`, `Tab`, `!rank`, выданные статусы, возврат управления после закрытия меню.

Прямой доступ к серверу для этих операций не требуется на этапе разработки. Production не обновляется автоматически.
