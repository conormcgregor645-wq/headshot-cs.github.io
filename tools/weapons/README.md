# Свои модели оружия

Модели оружия в CS2 показываются через свою запись в `scripts/weapons.vdata` аддона: плагин переключает
оружие игрока на неё (`ChangeSubclass`). В прошлый раз игра падала при входе: модели не попали в аддон
(Workshop Manager пакует только то, что собрано внутри аддона), а записи были скопированы не с того оружия
(модель под скелет кукри на записи обычного ножа).

`Build-Weapons.ps1` делает всё правильно и сам проверяет:

1. разбирает и собирает модели внутри аддона (через CS2-AG2-Port, без переделки анимаций);
2. берёт `weapons.vdata` из текущей версии игры и добавляет записи `weapon_tasher_<ключ>` — копии того
   оружия, чей скелет указан в самой модели;
3. компилирует, сверяет скобки и сохраняет на рабочий стол команды для сервера.

```powershell
powershell -ExecutionPolicy Bypass -File .\Build-Weapons.ps1 -Source "$env:USERPROFILE\Desktop\weapons" -Addon <аддон>
```

Перед заливкой обязательно проверь у себя: Workshop Tools → CS2 с аддоном → `map de_dust2`,
`sv_cheats 1`, `give weapon_tasher_<ключ>`.

После крупного обновления CS2: `.\Build-Weapons.ps1 -Addon <аддон> -VdataOnly` и перезалить аддон.
