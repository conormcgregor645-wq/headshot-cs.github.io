# Сервер TASHER

Серверная часть сайта tashercs.ru. Написана на Node.js 22 без сторонних библиотек, база данных — SQLite (один файл).

## Что уже работает на сервере

- Вход через Steam (настоящий, по OpenID), ник и аватар из Steam.
- Общая база игроков: баланс ТК и ₽, инвентарь, журнал всех операций.
- Кейсы: выпадение считается на сервере, бесплатный кейс раз в день.
- Продажа скинов сайту, апгрейд.
- Лента Live показывает настоящие выпадения.
- Админ-панель только для владельца и администраторов: начисление и списание ТК и ₽ с обязательной причиной.

Пока не перенесено (на сайте помечено «скоро»): джекпот, Фортуна, покупки в магазине, оплата, кланы, рейтинг и баны с игрового сервера CS2.

## Установка на VPS (Ubuntu 22.04/24.04 или Debian 12)

1. Зайти на сервер по SSH под root.
2. Выполнить:

   ```bash
   apt-get update && apt-get install -y git
   git clone --depth 1 https://github.com/conormcgregor645-wq/headshot-cs.github.io.git /opt/tasher
   bash /opt/tasher/server/deploy/install.sh tashercs.ru
   ```

3. Вписать настройки: `nano /etc/tasher.env`
   - `STEAM_API_KEY` — ключ со страницы https://steamcommunity.com/dev/apikey (домен: tashercs.ru). Без него вход работает, но не будет ников и аватарок.
   - `OWNER_STEAMIDS` — твой SteamID64 (17 цифр, можно узнать на steamid.io). Этот аккаунт станет владельцем.
   - Затем `systemctl restart tasher`.
4. В панели регистратора домена поменять A-запись `tashercs.ru` и `www` на IP сервера. Сертификат HTTPS выпустится сам за пару минут после обновления DNS.

Игровой сервер CS2 может стоять на той же машине: сайт занимает порты 80 и 443, CS2 — 27015.

## Команды

| Что нужно | Команда |
|---|---|
| Обновить сайт и сервер | `tasher-update` |
| Перезапустить | `systemctl restart tasher` |
| Посмотреть журнал | `journalctl -u tasher -n 100` |
| Сделать копию базы сейчас | `tasher-backup` |

База лежит в `/var/lib/tasher/tasher.db`, ежедневные копии за 14 дней — в `/var/backups/tasher/`.

## Проверка на своём компьютере

```bash
cd server
cp .env.example .env
node --env-file=.env app.js      # сайт откроется на http://localhost:8080
node test/smoke.js               # автоматическая проверка сервера
```

С `DEV_LOGIN=1` можно войти без Steam: `http://localhost:8080/auth/dev?steamid=76561190000000001`. На боевом сайте (https) этот режим не включается.

## Устройство

- `app.js` — веб-сервер, вход, все методы `/api/...`, раздача сайта.
- `lib/db.js` — таблицы базы. `lib/steam.js` — вход через Steam. `lib/game.js` — цены, кейсы, апгрейд.
- `data/cases.json`, `data/wdata.json` — каталог кейсов и цены скинов, выгружаются из сайта при сборке, чтобы сайт и сервер считали одинаково.
- Все изменения баланса идут через журнал (`ledger`): кто, сколько, за что, сколько стало.
